# Store review packet

Official store builds:

- contain only MarsTV-original abstract artwork and an original metadata-only
  demonstration catalog;
- contain no source URL, resolver URL, copyrighted poster, movie, episode, or
  public content directory;
- require the user to connect a private self-hosted instance or configure a
  local source they are authorized to use;
- do not download media and do not execute remote JavaScript;
- disable in-app binary updating in store channels;
- provide account export/deletion, privacy disclosure, child profile controls,
  and device revocation.

Reviewer instructions must use a dedicated test instance with the original demo
catalog. If playback validation is required, attach a private, time-limited
review source containing MarsTV-owned test media and remove it after review.

Required attachments for each release:

- platform privacy manifest/data safety form;
- screenshots for phone, tablet, TV, and desktop using original artwork;
- reviewer account or pairing instructions;
- source-code offer and third-party attribution;
- encryption/export-compliance answers;
- content authorization statement;
- account deletion URL and in-app path.
